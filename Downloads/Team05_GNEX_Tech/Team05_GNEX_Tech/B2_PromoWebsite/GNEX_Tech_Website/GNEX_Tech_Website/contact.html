FAQ

Common questions

Do staff need to install anything?

No. It runs in Chrome, Edge or Firefox on an ordinary PC. An offline version is available for classrooms.

Where is our data stored?

In your organisation’s own Supabase project, protected by row-level security. Learners only see their own results; administrators see their organisation.

Can we use our own procedures and questions?

Yes. Admins set the organisation name, incident-reporting contact, pass mark and add their own questions in the admin console.

Does it work on phones?

Dashboards, certificates and verification work on phones. The 3D game is designed for a laptop or PC.
