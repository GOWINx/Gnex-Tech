Case study

From prototype to SaaS in three releases

Each release answered real feedback. The client asked for role-based login, learner records and dashboards; we delivered all three, then went further with achievements, a certificate and a security model tested by 108 automated tests.

  1. 2 Sep 2026

    First contact

    Introduced GNEX Tech to the client and requested a demonstration.

  2. 11 Sep 2026

    Build 5.0 presented

    3D warehouse with six missions. Client sent nine improvement areas.

  3. 16 Sep 2026

    Update delivered

    Signed feedback form: login and roles, learner records, dashboards.

  4. 27 Sep 2026

    Build 6.0

    Supabase accounts, learner record, admin console, security hardening.

  5. 1 Oct 2026

    Build 6.1

    New game UI, lobby, 23 achievements, GNEX Tech certificate.

  6. 2 Oct 2026

    Final review and handover

    System demonstrated to the client for SaaS handover.
